# Content Architecture

Visitor logic outranks organizational presentation order.

Suggested homepage reasoning sequence (not a mandatory component list):
1. What is Tüskevár and who is it for?
2. Who may find it a good fit?
3. What if the child does not yet know which sport to choose?
4. Sports / choice guidance.
5. What is the first visit or joining process like?
6. What can child and parent expect?
7. Coaches/people, if verified information exists.
8. Genuine verified testimonials only.
9. Practical information.
10. Contact / clear next action.

Each page should have a clear audience, purpose, primary CTA and information hierarchy. The homepage should orient and route rather than explain everything.
