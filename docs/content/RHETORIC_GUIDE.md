# Rhetoric Guide

- Not every sentence should sound like a slogan.
- After a strong rhetorical sentence, use plain concrete explanation.
- Avoid repeated three/four-item abstract lists and repeated `nem X, hanem Y` constructions.
- Use recognizable parent/child situations: uncertainty before the first session, trying several sports, a shy child, a non-competitive child, losing motivation, finding a suitable activity.
- Curiosity may be used, but not manipulative clickbait.
- CTAs should name the action: `Sportágak megnézése`, `Edzésrend megnyitása`, `Kérdés küldése`, `Kapcsolatfelvétel`. Avoid vague CTA language such as `Fedezd fel`, `Lépj tovább`, `Kapcsolódj` when a concrete action exists.
