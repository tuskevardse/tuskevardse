# Content Evaluation

Qualitative targets after a full refactor:

| Dimension | Target |
|---|---:|
| Natural Hungarian | >= 9/10 |
| Parent clarity | >= 9/10 |
| Specificity | >= 8/10 |
| Rhetorical variety | >= 8/10 |
| Brand distinctiveness | >= 9/10 |
| Information architecture | >= 9/10 |
| CTA clarity | >= 9/10 |
| AI/marketing-language feel | <= 2/10 |

Scores are review gates, not scientifically objective measurements. Give a short justification for each.

Completion requires successful lint/build, no critical content-audit failure, rendered-page review, and documented exceptions/`NEEDS_VERIFICATION` items.
