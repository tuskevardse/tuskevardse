Átadási checklist

Ez a lista használható tényleges átadáskor. A pipák nem technikai funkciók, hanem ellenőrzési pontok.

1. Forráskód és fejlesztés

☐ GitHub repository URL átadva: https://github.com/tuskevardse/tuskevardse
☐ Átvevő GitHub hozzáférést kapott.
☐ Átvevő elfogadta a GitHub meghívót.
☐ Lokális telepítés kipróbálva: npm ci.
☐ Lokális dev server kipróbálva: npm run dev.
☐ Lokális lint sikeres: npm run lint.
☐ Lokális build sikeres: npm run build.

2. Git és release folyamat

☐ Alap branch tisztázva: main.
☐ Commit/push folyamat bemutatva.
☐ Git Credential Manager vagy más auth beállítva.
☐ Rollback mód tisztázva: git revert.
☐ Megállapodás van arról, mikor kell külön branch.

3. Cloudflare

☐ Cloudflare account hozzáférés átadva.
☐ Projekt neve ismert: tuskevardse.
☐ Build command rögzítve: npm run build.
☐ Deploy command / Pages output beállítás tisztázva.
☐ Deployments log helye bemutatva.
☐ Production URL és preview URL ellenőrizve.

4. Domain és DNS

☐ Domain regisztrátor tisztázva: ZTS / ZeroTime Services.
☐ ZTS hozzáférés átadva vagy felelős kijelölve.
☐ Cloudflare nameserverek dokumentálva.
☐ Webes DNS rekordok ellenőrizve.
☐ Mail rekordok DNS only módban vannak.
☐ MX/SPF/DKIM/DMARC aktuális állapot rögzítve.

5. Google Workspace és Calendar

☐ Google for Nonprofits státusz ismert.
☐ Google Workspace admin felelős kijelölve.
☐ Publikus Google Calendar tulajdonosa ismert.
☐ Naptárszerkesztők jogosultsága beállítva.
☐ Honlap eseményoldalán a naptár ellenőrizve.
☐ Google Forms/Drive használati szabályok tisztázva.

6. Tartalomkezelés

☐ Fő tartalmi fájlok helye ismert: content/.
☐ Oldalak helye ismert: app/.
☐ AI háttéranyag helye ismert: AI/.
☐ Dokumentáció helye ismert: docs/.
☐ Publikus programok Google Calendarban kezelendők.
☐ Tartalmi hangnem és gyerekadat-kezelési szabályok átbeszélve.

7. Biztonság

☐ Nincs titok a repositoryban.
☐ .secrets/ mappa célja ismert.
☐ API/billing nélküli működési elv ismert.
☐ Gyerekadat-kezelési korlátok rögzítve.
☐ Hozzáférés-visszavonási folyamat ismert személycsere esetére.

8. Átadás lezárása

☐ Átvevő lokálisan sikeresen buildelt.
☐ Átvevő készített próba commitot vagy bemutatta a folyamatot.
☐ Cloudflare deploy státusz sikeresen ellenőrizve.
☐ Domain és naptár production oldalon ellenőrizve.
☐ Felelősök és hozzáférési szintek dokumentálva.
