Projekt áttekintés

Ez a dokumentum az átvevő fejlesztőnek vagy üzemeltetőnek ad gyors képet arról, mi a projekt, hol található, milyen technológiával működik, és milyen költség- és üzemeltetési elvekhez kell igazodni.

1. Projekt azonosítók

  • Projekt neve: Tüskevár DSE honlap
  • Lokális munkamappa: C:\Projects\Tuskevar-DSE
  • GitHub repository: https://github.com/tuskevardse/tuskevardse
  • Alap branch: main
  • Cloudflare projekt neve: tuskevardse
  • Cloudflare Worker URL: https://tuskevardse.tuskevardse.workers.dev
  • Saját domain cél: https://tuskevardse.hu

2. Technológiai alap

  • Framework: Next.js
  • Publikálási modell: statikus export
  • Build kimenet: out/
  • Hosting: Cloudflare Workers/Pages statikus kiszolgálás
  • Forráskód és verziózás: GitHub
  • Lokális fejlesztés: Node.js + npm + Codex

3. Fontos fájlok és mappák

app/                 Next.js oldalak
components/          UI komponensek
content/             központi tartalmi adatok
AI/                  AI háttéranyag és másolható preprompt
docs/                üzemeltetési dokumentáció
docs/atadas/         átadási dokumentáció
public/              statikus assetek
scripts/             segédscriptek
package.json         npm parancsok és függőségek
next.config.ts       statikus export beállítása

4. Hosting és működési modell

A projekt normál működési lánca:

Lokális módosítás Codexszel
  -> npm run lint
  -> npm run build
  -> git commit
  -> git push
  -> GitHub
  -> Cloudflare automatikus build/deploy
  -> publikus honlap

5. 0 Ft-os működési elv

A működési cél: havi 0 Ft üzemeltetési költség a domain regisztrációs díján kívül.

Ehhez kerülni kell:

  • saját VPS-t vagy fizetős webtárhelyet,
  • fizetős backend szolgáltatást,
  • publikus weboldalhoz kötött fizetős API kulcsokat,
  • kártyaadatot igénylő automatikus Google Cloud vagy OpenAI API működést, ha nem vállalt költség,
  • olyan funkciót, amely szerveroldali állapotot vagy adatbázist igényel.

6. Jelenlegi integrációk

  • Google Calendar beágyazás az /esemenyek oldalon.
  • AI prompt másoló oldal az /ai-prompt útvonalon.
  • Kapcsolati űrlap mailto alapú megoldással.
  • Google Workspace nonprofit integráció tervezett irányként dokumentálva.

7. Átvevőnek szóló alapelv

A honlapot úgy kell továbbfejleszteni, hogy minden tartós változás a GitHub repositoryban legyen, és a produkcióba kerülés normál útja a GitHub push után induló Cloudflare deploy maradjon.
