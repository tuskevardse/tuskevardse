Tüskevár DSE átadási dokumentáció

Ez a csomag azt foglalja össze, mit kell átadni annak, aki a Tüskevár DSE honlap fejlesztését, üzemeltetését vagy karbantartását átveszi.

Átadási dokumentumok

01 - Projekt áttekintés

Projektcél, technológia, URL-ek, repository, hosting modell, 0 Ft-os működési elv.

02 - Fejlesztés és deploy

Lokális környezet, npm parancsok, tesztelés, GitHub workflow, Cloudflare deploy folyamat.

03 - Hozzáférések és biztonság

GitHub, Cloudflare, ZTS, Google, titkok, tokenek, gyerekadat-kezelési korlátok.

04 - Átadási checklist

Kipipálható lista arról, mit kell ténylegesen átadni az új fejlesztőnek vagy üzemeltetőnek.

Részletes háttérdokumentáció

Az átadási csomag a részletesebb üzemeltetési dokumentációra épül:

  • Rendszerarchitektúra és 0 Ft-os modell
  • ZTS domain és Cloudflare DNS
  • GitHub és Codex fejlesztési folyamat
  • Lokális tesztelés és produkcióba vitel
  • Karbantartási checklisták
  • Google Workspace nonprofit működés

Alapelv

Az átadásnál nem jelszavakat kell továbbítani, hanem kontrollált hozzáféréseket kell adni a megfelelő rendszerekben. Minden tartós módosítás Git commitként kerüljön a repositoryba.
